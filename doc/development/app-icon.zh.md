# 应用图标

本项目只构建 Android，图标全部位于 Android 资源目录中。本文说明需要什么格式的图片、放在哪里，以及如何用一张图替换全部图标。

## 需要什么样的图片

| 项目 | 要求 |
|---|---|
| 格式 | **PNG** |
| 色彩模式 | RGBA（支持透明）或 RGB |
| 建议尺寸 | **1024×1024 或更大**，正方形 |
| 色彩空间 | sRGB |
| 内容 | 无文字、无水印、无边框 |

一张 1024×1024 的 PNG 就足够，其余尺寸由脚本生成。**不要**手工缩放后再给我，缩放在安装时统一处理，避免多次重采样导致边缘发虚。

### 构图注意事项

| 事项 | 原因 |
|---|---|
| 主体约占画布 **70%** | 太小在桌面看不清，太满会被启动器遮罩裁掉 |
| 四周留白 | 自适应图标的安全区只有画布中心的 66% |
| 外轮廓清晰 | 桌面图标实际只有 48–192 像素 |
| 背景用纯色 | 渐变背景在小尺寸下会浑浊成一片 |
| 不要背景装饰（星星、光点） | 缩小后变成噪点 |
| 不要文字 | 缩小后变成墨点 |

## 图标目录

根目录：`android/app/src/main/res/`

按屏幕密度分五个目录，每个目录需要四个文件：

| 目录 | `ic_launcher.png` | `ic_launcher_foreground.png` | `ic_launcher_monochrome.png` | `ic_launcher_background.png` |
|---|---|---|---|---|
| `mipmap-mdpi` | 48×48 | 72×72 | 48×48 | 72×72 |
| `mipmap-hdpi` | 72×72 | 108×108 | 72×72 | 108×108 |
| `mipmap-xhdpi` | 96×96 | 144×144 | 96×96 | 144×144 |
| `mipmap-xxhdpi` | 144×144 | 216×216 | 144×144 | 216×216 |
| `mipmap-xxxhdpi` | 192×192 | 288×288 | 192×192 | 288×288 |

另有：

| 路径 | 用途 |
|---|---|
| `mipmap-anydpi-v26/ic_launcher.xml` | 自适应图标声明，把前景与背景层组合起来 |
| `assets/app_icon.png` | 512×512，项目展示用，不参与启动器显示 |

### 四个文件分别是什么

| 文件 | 作用 |
|---|---|
| `ic_launcher.png` | 传统图标。Android 8 以下使用；8 以上在启动器不支持自适应图标时使用 |
| `ic_launcher_foreground.png` | 自适应图标的**前景层**，透明背景，主体必须落在中心 66% 的安全区内 |
| `ic_launcher_background.png` | 自适应图标的**背景层**，铺满整个画布，会被遮罩裁剪 |
| `ic_launcher_monochrome.png` | Android 13+ 主题图标（Material You）的单色层，系统会自动着色 |

### 自适应图标的安全区

```
┌─────────────────────────┐
│        ↑ 可裁剪          │
│   ┌─────────────────┐   │
│   │                 │   │
│   │   安全区 66%     │   │  ← 前景层主体放这里
│   │                 │   │
│   └─────────────────┘   │
│        ↓ 可裁剪          │
└─────────────────────────┘
```

启动器会按自己的形状（圆形、方形、水滴形）裁剪，**安全区外的内容随时可能被切掉**。

## 如何替换

### 方法一：用脚本（推荐）

```powershell
python G:\dsh-audit\install_icon_from.py 你的图片.png
```

脚本会：

1. 裁成正方形（若输入不是正方形，取中心区域）
2. 生成五个密度的全部四个文件
3. 把图片缩进安全区作为前景层
4. 自动取图片主色作为自适应背景（也可用 `--background-color RRGGBB` 指定）
5. 更新 `assets/app_icon.png`
6. 把预览写到 `G:\dsh-audit\icon_preview\`

可选参数：

| 参数 | 说明 |
|---|---|
| `--background-color RRGGBB` | 指定自适应背景色，默认取图片平均色 |
| `--keep-background` | 用图片本身作为背景层（适合图片自带满幅背景时） |
| `--preview 目录` | 预览输出位置 |

### 方法二：手工替换

按上表尺寸准备 20 个 PNG，逐个替换。**不推荐**：手工缩放容易出现各密度边缘锐度不一致。

## 替换后

启动器可能缓存旧图标。卸载后重新安装即可看到新图标；仅覆盖安装有时仍显示旧图。
