# 条漫缩小与左右边距

English: [Reader side margins](reader_width.en.md)

在平板上觉得条漫填满屏幕太大时，可通过增加左右边距来缩小图片。在「设置 → 阅读器」或阅读器内的设置面板中，选择「连续（从上到下）」或「瀑布流（从上到下）」后，调整「条漫缩小（每侧边距）」。自动选择阅读模式的偏好包含这两种模式时，也会显示此设置。旧版本中该设置名为「左右边距（每侧）」。

每侧可设置为 0%～30%，默认 0%。例如设为 20% 时，左右各留出原内容宽度的 20%，图片居中显示，宽度为原来的 60%，高度按比例缩放。该设置仅作用于纵向连续和瀑布流阅读。

| 每侧边距 | 图片宽度 |
|---|---|
| 0% | 原来的 100% |
| 10% | 原来的 80% |
| 20% | 原来的 60% |
| 30% | 原来的 40% |

若开启「限制图片宽度」，先应用原有宽度限制，再按比例增加左右边距。因此这里的百分比以限制后的内容宽度为基准，并非始终以屏幕宽度为基准。

边距和宽度限制均遵循单本、设备、全局设置的优先级。阅读时调整边距会立即更新布局；恢复为 0% 即可取消额外留白，已有宽度限制仍然有效。

调整后保留当前章节和页码。双指缩放仍可用于临时查看细节；希望长期以较小尺寸阅读条漫时，使用此边距设置。
